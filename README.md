## 🎨 Project Overview

**Poetry Generator Web App** is a creative and visually appealing website built using **HTML, CSS, and JavaScript**. Users can generate beautiful poems with a single click, enjoy **soothing background music**, switch between **dark and light themes**, and easily **copy or save** their favorite poems. A custom **favicon** adds a professional touch to the browser tab.

## ✨ Features

- 📝 **Random Poetry Generation** on button click
- 🎶 **Background Music** plays during browsing
- 🌙 **Dark/Light Theme Toggle** for comfortable reading
- 📋 **Copy Poems** to clipboard with one click
- 💾 **Save Poems** as text files
- 🌐 **Responsive Design** works across devices
- 🎨 **Custom Favicon** visible on browser tab

## 🗂️ Folder Structure

```

NLP/
├── index.html         # Main webpage with poetry generator
├── style.css          # Styling including dark/light themes
├── script.js          # JavaScript logic for poems, theme toggle, copy/save, music
├── music.mp3          # Background music file
├── favicon.ico        # Custom favicon icon

````



## 🚀 How to Use

1. **Clone the repository**
   ```bash
   git clone https://github.com/Madhu1207-coder/NLP.git
   cd NLP


2. **Open the app locally**

   * Open `index.html` in any modern browser.

3. **Interact with the app**

   * Click **"Generate"** to create a new poem.
   * Use the **Dark/Light toggle** button to switch themes.
   * Press the **Copy** button to copy the poem text.
   * Press the **Save** button to download the poem as a `.txt` file.
   * Enjoy the **background music** as you explore.
